# Participant 09: final CSV

The main file, 09.csv, contains all stages; csv/ retains seven independent segment results.
Within each segment, retain valid shots in actual chronological order: the first 10 baseline, 140 training, and 30 test shots. No selection by score was performed.
strength_value is measured in O-to-B lengths and angle_value in degrees; both retains both components.
Components without reliable scoring evidence remain blank; strength_status/angle_status and needs_review retain reasons and review status.
audit/uncapped contains results before trial-count truncation, for provenance only; use the final main file or csv/ results for analysis.
Original videos, recording logs, and sessions were not modified; complete frame-level evidence is preserved in this project's working directory for this run.

Training contains 138 valid target-cushion contacts. Two additional online confirmations were reviewed in source frames and found to disappear into an upper corner pocket; return to the table was not confirmed, so they were not added as valid shots.
Training shots 25, 30, 49, and 68 were picked up before a natural stop was confirmed. Hand-carried passage across Y is not free-ball axis crossing; strength remains blank.
Natural stopping points for training shot 93 and test-both shot 15 were recovered by remeasurement of actual red-ball contours. Scoring rules, the model, and test-both angle values were unchanged.
