# Participant 08: final CSV

The main file, 08.csv, contains all stages; csv/ retains seven independent segment results.
Within each segment, retain valid shots in actual chronological order: the first 10 baseline, 140 training, and 30 test shots. No selection by score was performed.
strength_value is measured in O-to-B lengths and angle_value in degrees; both retains both components.
Components without reliable scoring evidence remain blank; strength_status/angle_status and needs_review retain reasons and review status.
audit/uncapped contains results before trial-count truncation, for provenance only; use the final main file or csv/ results for analysis.
Original videos, recording logs, and sessions were not modified; complete frame-level evidence is preserved in this project's working directory for this run.
